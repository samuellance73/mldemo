## Build Pipeline (`build.py`)

Run `python3 build.py` from the repo root. It does:

1. **`src/wrapper.py`** → `hf_deploy/wrapper.py`
   - Replaces `OBFUSCATE("some shell command")` with a reversed-base64 encoded string
   - Strips all `#` comment lines

2. **`src/Dockerfile`** → `hf_deploy/Dockerfile`
   - Replaces `URL_OBFUSCATE("https://...")` with `$(echo '<base64>' | base64 -d)`
   - Strips all `#` comment lines

3. **`src/app.py`** → `hf_deploy/app.py`
   - Strips all `#` comment lines (no other transforms)

4. **`src/README.md`** → `hf_deploy/README.md`
   - Copied verbatim

After running build.py, push `hf_deploy/` to Hugging Face.

## Key Design Rules

- **Only edit `src/`**. `hf_deploy/` is always regenerated by `build.py`.
- Use `OBFUSCATE("...")` in `src/wrapper.py` for any shell commands to obfuscate.
- Use `URL_OBFUSCATE("...")` in `src/Dockerfile` for any URLs to obfuscate.
- `numpy` is used for the fake CPU jitter matmul (comes free with `gradio`, no extra install).
- `torch` is NOT installed — it was removed to reduce image size (~700 MB savings).
- The startup log (`startup.log`) is captured via `tee` in the Dockerfile CMD.
