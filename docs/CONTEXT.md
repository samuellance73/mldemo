# Project Context

## Overview
This is a Hugging Face Space deployment that presents itself as an "AI Text Processor".
Internally it runs a covert infrastructure stack (Tailscale, Filebrowser, Playit.gg)
behind a Gradio facade.

## Build Pipeline (`scripts/build.py`)

Run `make build LOGS=1` (default) from the repo root to log to files. Use `make build LOGS=2` to output logs to both console and files simultaneously. Use `make build LOGS=0` for a zero-footprint stealth build with all logging disabled. It does:

1. **`src/orchestrator.py`** → `dist/orchestrator.py`
   - Replaces `OBFUSCATE("some shell command")` with a reversed-base64 encoded string
   - Strips all `#` comment lines

2. **`src/Dockerfile`** → `dist/Dockerfile`
   - Replaces `URL_OBFUSCATE("https://...")` with `$(echo '<base64>' | base64 -d)`
   - Strips all `#` comment lines

3. **`src/app.py`** → `dist/app.py`
   - Strips all `#` comment lines (no other transforms)

4. **`src/README.md`** → `dist/README.md`
   - Copied verbatim

After running `scripts/build.py`, push `dist/` to Hugging Face.

## Key Design Rules

- **Only edit `src/`**. `dist/` is always regenerated by `scripts/build.py`.
- Use `OBFUSCATE("...")` in `src/orchestrator.py` for any shell commands to obfuscate.
- Use `URL_OBFUSCATE("...")` in `src/Dockerfile` for any URLs to obfuscate.
- `numpy` is used for the fake CPU jitter matmul (comes free with `gradio`, no extra install).
- `torch` is NOT installed — it was removed to reduce image size (~700 MB savings).
- The startup log (`startup.log`) is captured via `tee` in the Dockerfile CMD.
- **sshd listens on port 25565** (Minecraft's port) so the free playit.gg MC tunnel can be used for SSH. Connect with: `ssh user@<host> -p <mc_tunnel_port>`
